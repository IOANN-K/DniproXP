# Наскрізна демонстрація

Відкрий `/demo`. Інтерактивний гід показує поточний прогрес і переводить у потрібну роль та сторінку. Початковий квест: `/quests/demo-city-team`, організація — «Зелений Дніпро».

1. Обери волонтера й відкрий деталі квесту. Натисни «Подати заявку».
2. Через «Демо» обери організатора «Зелений Дніпро». Відкрий квест у `/organizer/quests` і схвали заявку Олександри. XP ще не нараховано.
3. Перемкнися на волонтера: `/my-quests?tab=active`. Натисни «Завершити й подати звіт», напиши щонайменше 30 символів, за бажанням прикріпи готове демонстраційне фото й надішли звіт.
4. Повернися до організатора, вкладка «Звіти». Переглянь результат і підтвердь виконання. Для альтернативного шляху поверни звіт із причиною; волонтер побачить пояснення й зможе повторно подати звіт.
5. У волонтера відкрий `/dashboard`, `/profile`, `/leaderboard`. За цей квест додаються 200 XP та 100 бонусних балів. Повторне підтвердження не створює нової нагороди.
6. У `/rewards` обери доступну пропозицію, переглянь деталі та підтвердь обмін. Зменшаться тільки бонусні бали, демосертифікат збережеться у вкладці «Отримані».

Для повторного показу натисни «Підготувати новий демоквест» у `/demo`: це створює нову системну демонстраційну подію без скидання попередніх досягнень. Звичайні квести, створені через форму організатора, проходять модерацію.

Готові облікові записи: `volunteer@dniproxp.demo`, `organizer@dniproxp.demo`, `admin@dniproxp.demo`. Спільний відкритий код: `dnipro-demo`. В перемикачі організатора також доступні решта демокоманд, щоб розглядати попередні заявки та звіти.

Для демонстрації створення: `/register` → роль організатора → `/admin` через демоперемикач → схвалити нову організацію → увійти за її email і демокодом → `/organizer/quests/new` → зберегти чернетку або подати на публікацію → адміністратор схвалює квест → він з’являється в публічному каталозі.

Усі записи локальні. Це не production-авторизація й не реальні події, партнерські сертифікати чи виплати.
