# DniproXP frontend

## Структура

- `src/app`: React Router, TanStack Query provider, PublicLayout і навігація.
- `src/pages`: головна, каталог, деталі, мапа, рейтинг, нагороди, профіль та організатори.
- `src/features`: демосесія (єдиний Zustand store), запис і скасування участі.
- `src/entities`: моделі домену, QuestCard, іконки категорій.
- `src/shared`: локальні UI-компоненти shadcn-підходу (Radix + CVA), контейнери, форматування, storage.
- `src/mocks`: стабільний сценарій, 24 квести, 6 категорій, 5 організацій, 4 користувачі, досягнення та винагороди.

Tailwind 4 залишається підключеним через наявний Vite plugin. Токени Urban Friendly та адаптивні стилі розташовані в `src/index.css`, шрифт Manrope підключено локально через Fontsource з підтримкою кирилиці. `components.json` налаштовує shadcn/ui для `src/shared/ui`; alias `@` узгоджений у Vite та TypeScript.

## Сценарії

- `/`: повна головна з усіма тематичними секціями. Статистика й партнерства чітко позначені як демонстраційні.
- `/quests`: пошук за назвою/описом, категорія, район, дата, складність, мінімальні XP, три способи сортування та «Показати ще». Стан фільтрів зберігається в URL.
- `/quests/:id`: опис, вимоги, речі із собою, правила, організатор, схожі квести та участь.
- `/map`: список вибору квестів і OpenStreetMap embed. Координати умовні, для реальних зустрічей не використовуються; карті потрібен інтернет.
- `/leaderboard`, `/rewards`, `/profile`, `/organizers`: наповнені сторінки спільноти.

«Увійти» й «Долучитися» відкривають чесно позначений демопрофіль без збору персональних даних. Після входу можна записатися, скасувати участь і побачити свої записи у профілі. Mock service перевіряє місткість, повторний запис та завершений стан. `quest-8` заповнений, `quest-24` завершений; решта мають вільні місця. За запис XP не нараховується: підтвердження координатором ще не реалізоване.

Обмін XP списує локальний баланс і створює демонстраційний сертифікат у профілі. Повторне отримання й перевищення балансу заблоковані. Сертифікати не є справжніми пропозиціями партнерів.

Дані участі, демосесії та обміну зберігаються в localStorage під ключами `dniproxp:*:v1`. Для повернення до початкового сценарію видаліть ці ключі в налаштуваннях браузера. Дата сценарію фіксована: 16 жовтня 2026; дані не змінюються випадково між рендерами.

## Заміна mock API

`QuestApi` і `RewardsApi` у `src/mocks/api.ts` описують асинхронні контракти. Реальний транспорт має реалізувати ці інтерфейси, зберігши query keys `quests`, `quest/:id`, `participations`, `balance`, `redeemed` та інвалідацію після мутацій. Зараз жодна дія не звертається до NestJS; наявний Vite proxy збережений без змін.

## Межі перевірки

За умовою завдання test, lint, build, typecheck і dev не запускалися. Виконано форматування коду та ручний перегляд реалізації. Візуальну і браузерну перевірку потрібно виконати окремо після дозволу запускати застосунок. Backend не змінений.
